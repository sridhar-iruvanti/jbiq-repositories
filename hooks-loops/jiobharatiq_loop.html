Before Turn 1

Query patterns, feature affinity, hesitation and dwell time, corrections, incomplete tasks. Compounds with every session into an N=1 individual model from session 20+.

PUBLISH

Memory Agent — what gets written back after the response

Every conversation is a learning event. What's worth remembering is extracted, classified, and written to two stores.

Extract
Facts, preferences, life events, intent threads worth preserving. Confidence gating — noise filtered out. Contradiction detection — old preference overwritten when corrected.
Consent check
Session 3 prompt: Always / This Session Only / Never. "This Session Only" means session only — no silent overrides. PII blocked at pipeline level before any write.
Dual-write
Mem0 — near real-time, ready for next session. UCP writeback — async enrichment, flows to JioMart, JioHealth, JioCinema via Memory Read API.
What gets published from Subbalakshmi's session
Mother's diabetes management interest → episodic memory + JioHealth enrichment. Daughter's school form deadline → procedural memory (fires Tuesday reminder). Welfare scheme Tuesday pattern → procedural habit confirmed. Language = Tamil, voice-first = confirmed.
MEM0

Mem0 — the in-product memory store

Near real-time. Powers the next session's RETRIEVE step. Gets smarter with every conversation.

What it stores
Episodic memories (preferences, life events), procedural habits ("When X → do Y"), working memory from current session, semantic links to JioMart/JioHealth catalog.
Consolidation
Daily batch: similar memories clustered, LLM generates summary, originals archived. Target <50KB per user steady state. Quality maintained at 1M+ users.
User controls
My Preferences: see everything stored in plain language. Edit or delete in ≤3 taps. Pause mode — stops new additions without deleting existing. Deletion purge within 24 hours.
UCP WRITEBACK

UCP writeback — enriching the Reliance user profile

Every JBIQ conversation enriches the Unified Customer Profile that feeds every Jio surface. This is the flywheel.

What gets enriched
Interest signals, affinity scores, content preferences, inferred life-stage context. Updates feed JioMart category surfacing, JioHealth recommendations, JioCinema content signals.
Direction of flow
UCP → JBIQ (before Turn 1). JBIQ → UCP (async after each session). Two-way enrichment. No other AI product writes back to the user's ecosystem profile.
Consent boundary
Only declared and consented signals flow to partner surfaces. Health and personal disclosures are never surfaced proactively. Scoped by consent tier.
API

Memory Read API — signals flowing to every Jio surface

The layer that makes JioBharatIQ's memory compound across Reliance rather than staying inside the product.

What flows
Enriched interest signals, inferred category affinity, behavioural patterns. Not raw conversations — processed, consented signals only.
Who reads it
JioMart (commerce personalisation), JioHealth (relevant content and services), JioCinema (content discovery), JioSaavn (music and devotional curation).
The structural advantage
ChatGPT's memory stays inside ChatGPT. JioBharatIQ's memory compounds across Reliance. A user at session 30 has built something no other assistant can replicate without those 30 sessions.
