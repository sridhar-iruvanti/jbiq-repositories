3   5 discovery paths  ·  how users reach vertical content
01
Home feed slot
Core provides
Feed architecture, signal ranking, card template, 4-group structure
Vertical must bring
Context spec — what card shows, under which signal conditions, what it loads on tap
No context spec = not in feed
02
Persona tap
Core provides
Tap-to-context-load mechanism, domain routing
Vertical must bring
What loads on tap — which use case, with what preloaded context
Cold tap = vertical failure
03
Chat routing
Core provides
Intent recognition, routing logic, multi-turn handling
Vertical must bring
The use case experience that resolves the intent
Works even if user doesn't know vertical exists
04
Post-task next step
Core provides
Task completion detection, next-step trigger slot
Vertical must bring
The logical next step within that domain's journey
Highest intent moment — user just completed something
05
PN and WhatsApp
Core provides
Channel infrastructure, deep-link architecture, personalised hook from signal model
Vertical must bring
Trigger condition — what event warrants PN/WA and what specific hook to use
Generic hook = destroys channel trust

6   Vertical / inner page  ·  domain scope  ·  same structure, single domain
Vertical page structure and ownership
Every vertical page follows the same structure as the home page — persistent layer, Updates, For You, Continue, Discover, Moments — for consistency across the app. Within that structure, verticals have full ownership to build any use case or feature experience their domain needs.
Look and feel, avatar personality, tone of voice, content design, domain-specific value metrics, and the depth of experience within each feed slot — all owned by the vertical. The structure is the foundation. What gets built on it is entirely the vertical's.
New user  ·  first visit to this vertical*
Returning user  ·  has been here before*
* First visit vs returning is evaluated per vertical independently. A user can be a returning user at the app level but a new user to a specific vertical. Signal depth within that domain determines the experience state.
Objective
Prove value before user does anything
One clear first action. No history, no clutter. No explanation needed.
Feel like a home in this domain
Continuity first. Reward return immediately. Never restart cold.

7   Must not do
New user — never do this
Ask for preferences before delivering any value
Show empty Continue, history, or streak sections
Overwhelm with features before first query
Run tutorials or walkthroughs on entry
Require the user to know what to ask
Load a vertical with no context — cold tap is a failure
Show ₹0 or 0 hours saved on the value strip
Returning user — never do this
Show onboarding content or tooltips after session 1
Treat session 15 like session 1
Make them re-discover what they already use
Start a vertical cold when prior context exists
Send a generic WA or PN hook — specific or nothing
Show a round-number value gain — must be specific and real
Show a blank Continue to a retained user
