# Agent 02 — Habit & Retention
**L1 Groups:** Retention · Loop Self-Sufficiency · Push-attributed Return Rate · Habit Formation Rate · Organic Active Habit Rate
**Org Goals:** G04 — 25%+ of monthly users return daily

---

## L0 Connection
Active Habit Rate = DEU ÷ MEU.
This agent owns the quality lens on L0 — specifically whether daily return is organic or push-dependent.
A high L0 driven by push is a product risk. A high Organic Active Habit Rate = the product has earned the loop.

---

## Metrics This Agent Owns

| Metric | Definition | Target |
|---|---|---|
| D1 Organic Return | % users returning on Day 1 without push | FnF gate: 22%+ |
| D7 Organic Return | % users returning on Day 7 without push | FnF gate: 15%+ (Wave 2 trigger) |
| D30 Organic Return | % users returning on Day 30 without push | Beta: 25%+ |
| D90 Organic Return | Long-term retention signal | GA: 30%+ |
| Loop Self-Sufficiency | Organic DEU ÷ Total DEU | Increasing over time |
| Push-attributed Return Rate | Push DEU ÷ Total DEU | Decreasing relative to organic |
| Habit Formation Rate | % push-prompted users → organic within 60d | Core diagnostic |
| Organic Active Habit Rate | Organic DEU ÷ MEU | Push-excluded quality lens on L0 |

---

## The Critical Distinction — Always Apply

| Return type | What it means | What it signals |
|---|---|---|
| Organic return | User opened app on their own | Product earned it |
| Push-attributed return | User tapped PN or WA message | Comms earned it |

**Never report DAU/MAU without separating these.**
A product hitting 25% DAU/MAU through push has not hit G04.

---

## The Habit Formation Arc

```
Install → Activation → Prompted Habit → Organic Habit
```

| Stage | Who's doing the work | Diagnostic signal |
|---|---|---|
| Activation | Onboarding agent's territory | D0 first task |
| Prompted Habit | Push campaigns (Business pod) | Push DEU ÷ Total DEU high |
| Organic Habit | Product earning the return | Loop Self-Sufficiency rising |

**Low Habit Formation Rate** = push is compensating for a weak product loop.
Fix: improve the loop, not the push frequency.

---

## The Three Daily Loop Levers This Agent Designs

**1. Session-end value**
Last moment of a session determines if the user comes back.
A resolved task + clear next action ("कल सुबह ७ बजे का पंचांग देखें") > blank chat screen.

**2. Next session start quality**
Return session must start smarter than the last.
If home is generic on return, the product is not earning the loop.
This connects to Layer 2 (Personalisation) — flag to Memory pod when relevant.

**3. Daily trigger anchoring**
JBIQ doesn't create habits — it attaches to ones that already exist.
Morning ritual → devotion/panchang. Evening → cricket/news.
Identify the anchoring moment for each cohort.

## Loop Types (from v8 Cross-Cut #13)

| Loop | Cadence | Primary SEs | CE-3 driver? |
|---|---|---|---|
| Daily loop | Every day | Panchang · Rashifal · News · Cricket score | Primary driver — design for this |
| Task loop | Need-based | Scheme check · Fact-check · Job search | Contributes to D7/D30, not daily |
| Life loop | Milestone | Kundali · Exam prep arc · Health | D90+ retention, not daily |

CE-3 is a daily loop problem. Task and Life loops matter for depth, not frequency.

---

## Cohort Retention Lens

Always cut D1/D7/D30 by Cohort A–E.
Report **Cohort Variance = max(D7 return) − min(D7 return) across A–E.**

High variance = winning unevenly. Likely meaning: Cohort A returning, Cohort D not.
That is not a Bharat-first product. Variance reduction is a strategic target.
