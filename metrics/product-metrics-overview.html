02

Activity Units

›

All units anchored at the monthly level for consistency. MAU is the funnel diagnostic. MQU is the activity unit and the L0 denominator. MTU surfaces value delivered.

MAU · Monthly Active Users
Users who opened the app in last 30 days (rolling). Funnel diagnostic only — opened ≠ engaged.
MQU · Monthly Querying Users
Users who sent ≥1 query in last 30 days (rolling). The activity unit · L0 denominator.
MTU · Monthly Task Users
Users who completed ≥1 useful task in last 30 days (rolling). Monthly value-delivered unit.

Note: Active Habit Rate (L0) = Organic DQU ÷ MQU is a daily-stickiness ratio computed from these monthly bases — daily snapshots (querying users on a given day) are derived from MQU, not separate units to track.

›

A paired Product L0 sits at the top — both metrics must move together. Below it, 7 layers organised by user-experience question. Click any layer to expand.

North Star — paired L0
The Loop
Active Habit Rate
Organic DQU ÷ MQU
Tests: Did the product earn the user, or did push pay for the visit? (P7 — Build for the loop, not the visit.)

Composite (rollup): Compounding Habit Index = Active Habit × Useful Task. Useful for reporting; never a substitute for the pair.

04

Bharat Metrics — separate strategic frame

›

Bharat is not a layer of the product tree — it's a parallel strategic frame, reviewed alongside it. Inherits product metrics sliced by Cohort A–E, plus adds qualitative resonance signals.

Strategic Frame · Reviewed Quarterly
Does the product resonate with the users we built it for?
If the deeper user cohorts don't resonate, the strategic bet is failing — regardless of how headline metrics look.
L0 Bharat Persona Composite (BPC)
BPC = weighted average of Cohort Score across Cohorts A through E

Single number leadership tracks. Cohort Variance (max − min) is itself the diagnostic — a healthy average can hide one failing cohort.

Cross-Cutting Attributes

›

Every L0 / L1 in the tree must be sliceable by these. Every metric reported should carry the dimensions it was sliced by.

Cohort A · B · C · D · E
5 user cohorts per jbiq_user_cohort_gtm__v1.docx
Each cohort encapsulates language, device, geography, segment. Bharat L0, Active Habit, NPS, Useful Task — all slice by cohort.
Loop type
Daily · Task · Life
Mesh use-case framing. Active Habit Rate per loop type, per-experience retention.
Domain
12 daily-life domains
Daily Assistant · Entertainment · News · Jobs · Devotion · Astrology · Life Companion · Health · Finance · Commerce · Local Services · Govt Services. Useful Task Rate per domain.
Experience type
Vertical · Signature · Generic chat
Group G filter. SE Retention Lift, Coverage Delta, Generic→SE Conversion all anchored on this cut.
Modality
Voice · Text · Image
Voice is the Key Bet. Voice Primary User Share, modality switch success, per-modality completion.
Language
12 Indian languages
Hindi · English · Tamil · Telugu · Gujarati · Bengali · Marathi · Kannada · Malayalam · Punjabi · Odia · Assamese. ASR WER, Production Quality Floor, NPS, brand-voice adherence.
Device tier
Low-end · Mid-end · Flagship
Bharat-first means low-end must work. Latency, crash rate, voice abandonment.
Network type
4G · 3G · 2G
Voice runs on 3G; text on 2G. Per-network voice latency, task completion.
Surface
Home · Persona page · Suggestion tile · Widget · Deep link · Notification
Surface time-to-meaningful, widget tap rate, surface-driven personalization.
Time horizon
D1 · D7 · D30 · D90
Retention curve, cohort analysis, all return rate metrics.
Acquisition channel
Jio retail · MyJio · JioFiber · Organic · Paid · Referral
Per-channel D7 organic return — separates real users from vanity installs.
Session depth
Single-turn · Multi-turn (≥3) · Extended (≥5)
Multi-turn Coherence, Engagement metrics, conversation quality.
Time of day
Morning · Day · Evening · Night
Adaptive engagement (next-prompt), Personalization, contextual greeting.
Day of week
Weekday · Weekend
Engagement frequency, weekend-specific use cases.
Region
Urban · Tier-2 · Tier-3 · Rural
Per-region latency, distribution-derived cohort cuts, Bharat segment composite.
Skill class
1P · 2P · 3P · Generic chat
Partner skill share, per-partner task completion (Layer 7).
