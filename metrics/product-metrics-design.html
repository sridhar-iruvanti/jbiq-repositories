All 7 layers · L0 / L1 / L2 · Definitions · Reference

Design principle: Every metric is derivable. L0 is the outcome. L1 is what drives it. L2 is where you look when L1 moves. Complexity lives at the bottom, not the top.
Direction: Layers 1–5 are user-backwards. Layer 6 is system-backwards. Layer 7 is org-backwards.

MAU— opened the app in last 30d
  └── MEU— query OR audio/video ≥10s in last 30d  (MQU ∪ MCU)  ·  Primary engaged base
        ├── MQU— ≥1 query (text / voice / image). All queries are tasks. MQU ⊂ MEU.
        └── MCU— ≥1 audio/video played ≥10s. Card taps are surface events, not MCU.
Useful Task — a task that resolved AND user signaled value. ALL of: no rephrase within 60s · no thumbs-down · no restart. Plus ≥1 positive: continued · domain return 24h · thumbs-up.
A query is a task. One user intent can span multiple queries.
